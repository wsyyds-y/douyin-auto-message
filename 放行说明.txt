【如果 Windows 提示"已阻止威胁"，请照这里做】

────────────────────────────────
为什么会被拦？
────────────────────────────────
这个程序没有花钱买「数字签名证书」，而且它要创建一个"定时任务"（每天自动发消息用）。
Windows 杀毒软件看到「没有签名 + 创建定时任务」，容易误判成病毒——这是误报，不是病毒。

────────────────────────────────
第 1 步：让 Windows 放行
────────────────────────────────
1. 在开始菜单搜索「Windows 安全中心」，打开它
   （或双击右下角任务栏的盾牌图标）
2. 点左侧「病毒和威胁防护」
3. 点「保护历史记录」
4. 找到名字叫 Behavior:Win32/Execution.A!ml 的那一条，点开它
5. 点「操作」→ 选择「允许在设备上」
6. 如果程序已经被删掉了：回到压缩包，重新解压一次

────────────────────────────────
第 2 步（建议做，一劳永逸）：把程序文件夹加进排除项
────────────────────────────────
1. Windows 安全中心 →「病毒和威胁防护」
2. 找到「病毒和威胁防护设置」→ 点「管理设置」
3. 拉到页面最下面，找到「排除项」→ 点「添加或删除排除项」
4. 点「添加排除项」→ 选「文件夹」
5. 选中你解压出来的 DouyinAutoMessage 文件夹 → 确定

做完这两步，再双击 DouyinAutoMessage.exe 就能正常打开。

注意：排除项只影响这一个文件夹；以后不想用了，
在同一个页面把它删掉即可（卸载程序也会提示你清理）。

────────────────────────────────
还是打不开怎么办
────────────────────────────────
1. 把拦截提示截图
2. 或者打开程序里的「查看日志」，点「复制全部」
3. 把截图 / 复制的内容发给维护者

────────────────────────────────
补充：这个程序会改你电脑的什么
────────────────────────────────
1. 创建两个计划任务：DouyinAutoMessageMorning、DouyinAutoMessageEvening
2. 在 %LOCALAPPDATA%\DouyinAutoMessage 里存配置、登录状态和日志
3. 不改注册表、不改系统设置、不动你日常用的 Edge 数据
4. 程序里有「卸载并清理」按钮，可以一键全部撤销
