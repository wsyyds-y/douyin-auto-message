抖音自动发消息 1.2 · 使用说明
=================================

【这是什么】
每天早晚（时间可改）自动打开抖音网页版，给指定好友各发一条祝福语。
全部在本机完成，不需要安装 Python，也不需要装任何运行库，只需要系统自带的 Edge 浏览器。

【第一次使用（5 步）】
1. 双击 DouyinAutoMessage.exe
2. 点「登录抖音」，在弹出的浏览器窗口里用抖音 App 扫码；登录成功后窗口会自己关闭
3. 在「发送对象」里添加好友昵称（和抖音私信里能搜到的一致即可，符号可以省略）
4. 在「祝福语」里写内容，一行一条，会按日期自动轮换
5. 点「立即发送一次」，确认第一个好友能收到
6. 最后点「保存并启用定时任务」
   → 会先弹出风险清单，看完勾选「我已知晓」才能启用

【界面上每个按钮】
- 保存设置            只保存，不启用定时任务
- 登录抖音            打开浏览器扫码登录（只需要一次）
- 立即发送一次        真的给第一个好友发一条，用来验证
- 保存并启用定时任务  先看风险清单，确认后按时间自动运行
- 查看日志            直接在程序里看每天的运行记录，可以一键复制
- 自我检查            检查 Edge / 登录 / 人数 / 祝福语 / 定时任务是否正常
- 打开数据目录        打开配置文件所在的文件夹

【出错了怎么办】
所有错误都会弹出中文提示，提示框里有一个「复制」按钮：
1. 点「复制」
2. 把复制到的内容发给维护你的人
（日志里已经包含时间、失败原因和截图位置，维护者一看就知道怎么改。）

如果定时任务在没人看着的时候失败，桌面会弹出一个提示框，
告诉你「有 N 位好友没发出去」，同样点开程序里的「查看日志」复制即可。

【运行时会看到什么】
- 到点自动弹出浏览器窗口，大约 1 分钟，不需要操作
- 这段时间系统会被静音，结束后自动恢复原来的音量
- 所有好友发完后浏览器自动关闭
- 锁屏状态下可以正常运行
- 电脑必须开机、Windows 必须处于登录状态；睡眠了会在唤醒后补跑

【要求】
- Windows 10 / 11（自带 Edge 浏览器，请不要卸载）
- 只需第一次扫码登录，之后会记住登录状态

【数据存放位置】
%LOCALAPPDATA%\DouyinAutoMessage
  config.json    配置文件
  profile\       登录状态（含 cookie，不要外传）
  logs\          每天的运行日志
  shots\         失败时的截图
  crash.log      程序启动失败时的记录

【怎么卸载】
1. 打开「任务计划程序」，删除 DouyinAutoMessageMorning 和 DouyinAutoMessageEvening
2. 删除程序文件夹，以及 %LOCALAPPDATA%\DouyinAutoMessage

【常见问题】

- 遇到问题：去 GitHub 仓库（douyin-auto-message）开 Issue，把「查看日志」复制的内容贴上去
- 「找不到 Edge 浏览器」：先安装 Microsoft Edge
- 「登录没有完成」：重新点「登录抖音」，确认手机上点了允许
- 日志里出现「页面被验证码/登录拦住」：登录过期，重新扫码即可
- 某个好友一直发失败：多半是昵称和私信里显示的不一致，看「查看日志」里
  「搜索『xx』命中：…」那一行，核对是不是同一个人
- 杀毒软件 / SmartScreen 提示：程序未做数字签名，选择「更多信息 → 仍要运行」
